# Conversor de Temperatura | Ejercicio de Lógica en JavaScript

---

## Descripción del Proyecto

Este proyecto es una solución algorítmica desarrollada en **JavaScript** enfocada en la práctica de lógica de programación, manejo de estructuras de control, validación rigurosa de entradas numéricas (`data validation`) y manipulación de consola.

El programa solicita al usuario una temperatura en **grados Celsius (°C)** y realiza las conversiones equivalentes a:
*   **Grados Kelvin (K)**
*   **Grados Fahrenheit (°F)**

---

## Requisitos e Instrucciones del Ejercicio

El script cumple con los siguientes requerimientos técnicos y funcionales:

1.  **Captura de datos:** Solicitar la temperatura en Celsius mediante un `prompt`.
2.  **Validación estricta de tipos:** Identificar si el valor ingresado es un número válido. Si la entrada no es de tipo numérico, muestra un mensaje de error intuitivo y solicita nuevamente los datos hasta obtener una entrada válida.
3.  **Procesamiento y Fórmulas:**
    *   **Celsius a Kelvin:** $K = °C + 273.15
    *   **Celsius a Fahrenheit:** °F = (°C × 1.8) + 32
4.  **Salida de Resultados:** Imprimir los valores convertidos directamente en la consola.
